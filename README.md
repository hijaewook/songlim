# PROJECT WRECKED ONLINE

원본 `PROJECT_WRECKED_v0.5_확장판.html`의 게임 콘텐츠와 렌더링을 유지하면서
온라인 멀티플레이 계층을 추가한 버전입니다.

## 온라인 구조

- 최대 4명 접속
- 기본 플레이어 캐릭터:
  - 김우찬
  - 김효창
  - 김필재
  - 유지환
- 서로 같은 캐릭터 중복 선택 불가
- 빈 자리는 기존 AI가 그대로 담당
- 첫 접속자가 HOST
- HOST가 원본 게임 시뮬레이션을 실행
- 다른 플레이어는 입력을 HOST에 전송
- HOST가 게임 상태를 다른 플레이어에게 동기화
- 플레이어가 나가면 해당 캐릭터는 다시 AI가 담당
- HOST가 끊기면 남은 플레이어 중 한 명을 새 HOST로 승격하고 마지막 스냅샷으로 이어서 진행

이 구조는 원본 게임 로직을 서버용으로 새로 재작성하지 않고 그대로 유지하기 위해 선택했습니다.

## 로컬 실행

Windows:
`run.bat`

접속:
`http://127.0.0.1:8000`

두 PC가 같은 LAN이면:
`http://서버PC_IPV4:8000`

## 인터넷 배포

현재 GitHub/Render 프로젝트를 그대로 사용하는 경우:

1. `publish_update.bat` 실행
2. GitHub `hijaewook/songlim`에 push
3. Render의 기존 `songlim` 서비스가 자동 재배포
4. 기존 `https://...onrender.com` 주소로 접속

## 게임 참가

1. 모든 사람이 같은 Render URL 접속
2. 같은 방 코드 입력
3. `방 접속`
4. `캐릭터 선택으로`
5. 각자 서로 다른 기본 캐릭터 선택
6. 방장이 `원정 시작`
7. 빈 자리는 AI 동료가 담당

## 주의

원본이 1인 조작 + AI 3인 구조로 작성되어 있었기 때문에,
온라인 버전은 원본 플레이 감각을 보존하기 위해 HOST-authoritative 방식으로 동기화합니다.

성장/보상 선택 UI는 현재 원본과 동일하게 HOST의 런 진행을 기준으로 처리됩니다.
전투 중에는 각 온라인 참가자가 자신의 캐릭터 이동/공격/Q/E/R/회피/오의를 직접 조작합니다.
